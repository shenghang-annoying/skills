# 技术汇报 PPT Skill（tech-report-deck）

一句话风格：**蓝图工程感 + 编辑排版** —— 干净利落、版式规整、零冗余装饰。
核心原则：每页只讲一个主张；编号贯穿；技术名词一律等宽字体；深浅节奏交替。

---

## 1. 工作流（必须按顺序）

1. **先出大纲**：列出章节结构 → 每页一行（页型 + 一句话主张）→ 交用户确认。
   - 经典五章：`背景 → 能力/方案 → 架构 → 价值与边界 → 计划`，按题材可增删。
   - 章节页（divider）数量 = 章节数；正文页控制在 15–25 页。
2. **大纲确认后再写代码**：一次性输出完整单文件 HTML（fenced code block），不拆分、不省略。
3. **预览迭代**：用户提修改 → 只改指定页，保持设计体系不变。
4. **导出**：按 `P` 进入打印模式 → 导出 PDF → 转 PPTX（告知用户此路径）。

---

## 2. 设计 Tokens（根级 CSS 变量，不得偏离）

```css
:root{
  --paper:#f3f5f8;      /* 页面底色 */
  --paper-2:#ffffff;    /* 卡片底色 */
  --ink:#0b1220;        /* 主文字 / 深色块 */
  --ink-2:#39435a;      /* 次级文字 */
  --muted:#7d869b;      /* 弱化文字 */
  --line:rgba(11,18,32,.13); /* 分隔线 */
  --blue:#1a45d6;       /* 主强调色 */
  --blue-soft:#e7ecfd;
  --cyan:#0a8fb0;       /* 第二强调（工具/数据） */
  --cyan-soft:#e2f4f9;
  --amber:#d97706;      /* 第三强调（注意/人工） */
  --amber-soft:#fdf0e0;
  --green:#0f7a5a;      /* 结果/成功 */
  --backdrop:#0c111a;   /* 舞台外背景 */
}
```
